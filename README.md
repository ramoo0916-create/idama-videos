# فيديوهات «مميزات إدامة» للنشر في إنستقرام

- `videos/` : فيديو 30 ثانية لكل ميزة (منسوخة من فرع `video-kit` في مستودع idama بتاريخ 22 نوفمبر 2026).
- `captions.json` : لكل يوم: الرقم والعنوان ومسار الفيديو والنص الجاهز للنشر.
- `posted.json` : أين وصل النشر. `next_day` هو اليوم التالي الذي يُنشر، و`posted` سجل ما نُشر (اليوم والتاريخ والرابط).

المهمة المجدولة «نشر فيديو إدامة اليومي في إنستقرام» تقرأ هذا المستودع كل يوم، وتنشر فيديو واحداً في حساب @idamaapp، ثم تحدّث `posted.json`.
اليوم 1 غير موجود هنا (لم يُحفظ في الفرع)، والأيام 2 و3 موجودة احتياطاً فقط؛ النشر يبدأ من اليوم 4.
